# Shop Background Image Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an optimized WebP background image to all three神秘商店 (Mystery Shop) pages via a shared layout wrapper.

**Architecture:** A one-time Node script converts the 19MB PNG to a ~300KB WebP; a new `ShopLayout.vue` component applies it as a fixed CSS background; the shop router is restructured to nest all three shop routes under that layout.

**Tech Stack:** Vue 3, Vue Router 4, Tailwind CSS, sharp (image processing, devDep)

### Task 1: Install sharp and generate public/shop-bg.webp

**Files:**
- Create: `scripts/convert-shop-bg.js`
- Create: `public/shop-bg.webp` (generated)

- [ ] **Step 1: Install sharp as devDependency**

```bash
npm install --save-dev sharp
```

Expected: `package.json` gains `"sharp": "^0.x.x"` under `devDependencies`.

- [ ] **Step 2: Create scripts/convert-shop-bg.js**

```js
import sharp from 'sharp';
import { fileURLToPath } from 'url';
import { dirname, join } from 'path';

const __dirname = dirname(fileURLToPath(import.meta.url));
const input = join(__dirname, '..', 'shop-background.png');
const output = join(__dirname, '..', 'public', 'shop-bg.webp');

const info = await sharp(input)
  .resize({ width: 1920, withoutEnlargement: true })
  .webp({ quality: 85 })
  .toFile(output);

console.log(`Done: ${output}`);
console.log(`  ${info.width}x${info.height}, ${(info.size / 1024).toFixed(0)} KB`);
```

- [ ] **Step 3: Run the script**

```bash
node scripts/convert-shop-bg.js
```

Expected output (exact numbers will vary):
```
Done: /…/public/shop-bg.webp
  1920x1072, 287 KB
```

The output size should be well under 1000 KB. If it exceeds 1MB, lower `quality` to `75` and re-run.

- [ ] **Step 4: Verify the file exists**

```bash
ls -lh public/shop-bg.webp
```

Expected: file present, size in the hundreds of KB range.

- [ ] **Step 5: Commit**

```bash
git add public/shop-bg.webp package.json package-lock.json scripts/convert-shop-bg.js
git commit -m "feat: add optimized WebP background for shop pages"
```

### Task 2: Create ShopLayout.vue

**Files:**
- Create: `src/games/shop/ShopLayout.vue`

- [ ] **Step 1: Create the layout component**

```vue
<template>
  <div class="shop-bg flex-1 flex flex-col">
    <router-view />
  </div>
</template>

<style scoped>
.shop-bg {
  background-image:
    linear-gradient(rgba(10, 5, 2, 0.45), rgba(10, 5, 2, 0.45)),
    url('/shop-bg.webp');
  background-size: cover;
  background-position: center;
  background-attachment: fixed;
}
</style>
```

The `linear-gradient` overlay is a uniform semi-transparent dark layer that preserves text readability while letting the background image show through. The `url('/shop-bg.webp')` path is absolute from the site root — Vite serves `public/` at `/`, so this resolves correctly in both dev and production.

- [ ] **Step 2: Commit**

```bash
git add src/games/shop/ShopLayout.vue
git commit -m "feat: add ShopLayout with fixed background image"
```
