# 神秘商店游戏页面排版重设计

**日期：** 2026-07-03  
**涉及文件：**
- `src/games/shop/pages/PlayPage.vue`
- `src/games/shop/components/FeedStream.vue`

---

## 背景

当前 PlayPage 三栏布局（`260px | 1fr | 340px`）存在以下问题：
- 左右侧栏宽度不对称（右比左宽 80px），视觉失衡
- 游戏核心数据（保底、得吃）和操作按钮（结算记录、抽奖记录）分散在 header 右侧，与「店内成员」的关联性弱
- FeedStream 硬限 `max-h-[420px]`，高分屏下方留白过多
- 手机端成员列表竖排，占用大量纵向空间

---

## 设计目标

1. 中间抽奖/装备区是核心操作区，视觉上最突出
2. 将本局数据与成员信息聚合到一个面板，减少 header 信息密度
3. 左右侧栏对称收窄，给中间更多空间
4. 手机端体验更紧凑，成员信息不占主内容位置

---

## 设计方案

### 1. 整体列宽调整

| | 旧值 | 新值 |
|---|---|---|
| 左侧（信息面板）| 260px | 220px |
| 中间（抽奖/装备）| 1fr | 1fr（不变） |
| 右侧（小报童）| 340px | 260px |

Grid 声明：`lg:grid-cols-[220px_1fr_260px]`

### 2. 左侧面板重构：信息面板

原来只展示「店内成员」列表，重构为三段式布局（从上到下）：

**① 本局数据（新增）**
- 2 列网格展示「保底」和「得吃」两个数值
- 样式参考原 header badge：`border border-gold-500/40 bg-ink-700/60`
- 保底用金色（`text-gold-200`），得吃用绿色（`text-forest-300`）

**② 操作（新增）**
- 「⚖ 本轮结算」按钮：`btn-boss`，仅 `canSettle`（房主 + PLAYING 状态）时显示
- 「结算记录」按钮：`btn-ghost`
- 「抽奖记录」按钮：`btn-ghost`
- 按钮字号缩小为 `text-[11px]`，`py-1.5 px-3`

**③ 店内成员（保留原逻辑）**
- 玩家卡片样式不变
- 标题从 `h3` 调整为与上方两段保持一致的 section title 风格

### 3. Header 简化

从 header 中移除以下元素：
- 「保底」badge
- 「得吃」badge
- 「⚖ 本轮结算」按钮
- 「结算记录」按钮
- 「抽奖记录」按钮

Header 保留：
- 左侧：⚜ 图标 + 标题「花栗鼠的神秘商店」+ 口令
- 右侧：「离开」按钮

### 4. FeedStream 高度自适应

- 删除 `max-h-[420px]`
- 改为 `flex-1 overflow-y-auto`，随侧栏高度自动伸展
- 外层 card 改为 `flex flex-col h-full`（已有 flex flex-col，补充 `h-full`）
- 加 `lg:sticky lg:top-24`，与左侧面板行为一致

### 5. 手机端布局

`grid-cols-1` 下各区块顺序（通过 `order` 控制）：

| order | 内容 |
|---|---|
| 1 | 抽奖/装备主区（核心内容，最优先） |
| 2 | 左侧信息面板（本局数据 + 操作 + 成员，整块下移） |
| 3 | 小报童（`max-h-[280px]`，手机适当缩小） |

手机端信息面板内，成员列表改为横向三格并排（`flex flex-row gap-2`），每格显示头像 + 昵称（截断）+ 金币，比竖排节省约 60% 纵向空间。本局数据和操作按钮保持竖向堆叠，不需要折叠交互。

---

## 不变的部分

- LotteryPanel 内部逻辑与样式不变
- EquipmentShop 内部逻辑与样式不变
- FeedStream 内部事件渲染逻辑不变
- PlayerSlot 组件不涉及

---

## 影响范围

- 只改动 `PlayPage.vue` 的 template 布局部分（header、main grid、aside）
- `FeedStream.vue` 改动极小（外层容器高度类名）
- 无需改动 store、游戏逻辑、协议

---

## 验收标准

1. 桌面（>= 1024px）：三栏可见，左右对称，中间最宽
2. 中等屏幕（768–1023px）：单列堆叠，顺序正确
3. 保底/得吃数值在左侧面板实时更新，与 header 原行为一致
4. 房主看到「本轮结算」按钮，非房主不可见
5. 小报童在高分屏不留白，可滚动
6. 手机端成员横排，不遮挡主内容
